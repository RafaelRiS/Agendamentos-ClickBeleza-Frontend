# 💇‍♀️ ClickBeleza - Frontend

Interface web para agendamento de serviços de beleza.

---

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

---

## 📦 Funcionalidades

- Seleção de serviço
- Escolha de profissional
- Escolha de data e horário
- Validação de horários disponíveis
- Confirmação com animação (slider)
- Página "Meus Agendamentos"
- Página Admin (gerenciamento completo)

---

## ⚙️ Como rodar o projeto

### 1. Clonar o repositório
```bash
git clone https://github.com/RafaelRiS/Agendamentos-ClickBeleza-Frontend.git
Instale as dependências com o comando no terminal: 'npm install'
Agora inicie com o comando no terminal: 'npm run dev'
```

## ⚠️ ATENÇÂO: Certifique-se de que o backend (https://github.com/RafaelRiS/Agendamentos-ClickBeleza-Backend.git) está rodando!
